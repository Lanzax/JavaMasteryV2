# JavaMastery MVP

Piattaforma web dark per imparare programmazione. Questa prima fase include solo il modulo Java, con architettura estendibile per HTML, CSS, React e Spring.

## Comandi

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Roadmap

1. Integrazione Monaco Editor completa.
2. Executor Java reale via Docker sandbox.
3. Workspace multi-file per progetti.
4. Moduli HTML/CSS/React/Spring completi.
